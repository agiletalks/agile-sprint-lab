## 完整端到端流程

本機透過 `npm run test:e2e` 一鍵啟動隔離服務，另驗證六條操作旅程：

1. P00→P25 完整 120 分鐘流程：以固定瀏覽器虛擬時鐘推進，所有頁面到時不自動換頁；13 步驟全部結束，實際活動秒數合計 7,200，待處理配額為零。
2. 按鈕焦點後的換頁、輸入欄位快捷鍵隔離、Esc，以及控制台開啟時倒數持續。
3. 透過控制台操作略過、回看、重新排入、捨棄與配額轉移，確認未用時間守恆與面板展開狀態保留。
4. running 狀態重新整理保留原截止時間；模擬背景延遲後正確歸零。
5. 真正下載 JSON 備份、清除、取消還原、同檔重試、確認還原，以及拒絕無效備份。
6. 測試圖檔原始 bytes 不變，設定與 Logo 嵌入匯出 HTML；隔離且斷網的新 file:// 環境仍可設定組隊、換頁與產生 QR。

這些是瀏覽器操作測試，不是等待真實兩小時。逐次執行結果與紀錄以 `projection/reports/latest.html`／`latest.json` 為準。本機 `/test-results` 可查看結果與代表截圖。
