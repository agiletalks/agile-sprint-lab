# 本機端到端測試

本機投影：http://127.0.0.1:4173

本機測試報告：http://127.0.0.1:4173/test-results

不需 ChatGPT、GitHub 或 Google Cloud 登入；執行與測試均可在本機完成。

## 直接使用

- 離線：雙擊 `projection/Agile-Sprint-Lab-Projection.html`，用 Chrome 開啟即可。
- 本機服務：雙擊根目錄 `Start-Projection.command`，保留 Terminal 視窗，再開上方本機網址。也可在根目錄執行 `npm start`。
- 如果原服務仍在執行，直接使用既有網址；啟動腳本會提示連接埠已被使用。
- 伺服器只監聽 127.0.0.1，不會提供其他手機上傳或公開網站。

## 一個指令重跑全部檢查

在根目錄執行：

```sh
npm run test:e2e
```

macOS 也可雙擊根目錄的 `Test-Projection.command`。

此指令會自動啟動獨立、隨機連接埠的測試服務，再執行：

1. 計時與流程狀態核心測試。
2. 26 頁 × 兩種解析度 × 三種語言，共 156 組版面檢查。
3. 控制台、語言、QR、到時提醒、進度匯出與儲存備援。
4. P00 至 P25 完整工作坊，使用虛擬時鐘推進全部 120 分鐘；每頁歸零都檢查不會自動換頁。
5. 跳頁、重新排入、捨棄與配額轉移，以及進行中重新整理。
6. 實際下載進度、清除、取消還原、再次選擇同檔與確認還原。
7. 測試圖檔原始 bytes、設定與 Logo 嵌入匯出的 HTML，再用隔離、無網路、file:// 環境開啟操作。

測試使用獨立瀏覽器，不會改動你正在操作的場次。結束後會關閉自建的測試服務；正常本機服務保持原狀。瀏覽器會優先使用 Playwright 已安裝版本，macOS 也會自動尋找已安裝的 Chrome。沒有可用瀏覽器時，才需要先連網執行 `npx playwright install chromium`。測試依賴已由 package-lock.json 鎖定，不會在測試過程自動下載套件。

結果保存在 `projection/reports/latest.html` 與 `latest.json`。可直接開啟 HTML 閱讀結果；透過本機服務的 `/test-results` 閱讀時，代表畫面連結也可直接開啟。逐頁與狀態截圖在 `projection/screenshots/`。

## 約五分鐘的人工試用

1. 在 P00 按「開始工作坊」，確認 P01 倒數開始；按 Space 暫停。
2. 按 P 開啟控制台，把剩餘設為 `00:10`，再開始。確認歸零後留在同頁。
3. 點「下一頁」：應等待開始；點「下一頁並開始」：應立刻倒數。
4. 提早往後換頁後，展開「待處理配額」，試用重新排入與轉移；回看舊頁不會自動開始。
5. 切換三種語言，確認目前頁與剩餘時間保留；按 T 隱藏／顯示倒數。
6. 跳到 P17，指定 `03:01` 後開始，確認三分鐘提醒出現且不遮住指示。
7. 暫停並重新整理，確認原頁與剩餘值保留。
8. 匯出進度備份，清除進度，再還原該備份；清除與還原前都可取消。
9. 不填上傳網址時，P18 不應有 QR；填有效網址後才顯示。
10. 匯出離線單檔，斷網後開啟；最後在 P25 隱藏倒數，確認聯絡信箱仍可見。

控制台會出現在投影，開啟面板不會暫停活動。僅開一個實際操作分頁。

Logo 原圖未提供時使用文字品牌；測試內的微小圖檔只在隔離測試環境使用，沒有存入正式投影。Safari／Edge 與會場實際投影、音訊輸出仍待現場驗證。
